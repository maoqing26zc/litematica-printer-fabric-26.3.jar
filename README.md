# Litematica Printer 二改版 · Minecraft 26.3

把 [B站 @宅咸鱼](https://space.bilibili.com/31545812)（GitHub：[zhaixianyu](https://github.com/zhaixianyu/litematica-printer)）的**投影打印机二改版**移植到 **Minecraft 26.3**。

保留了原版的**挖掘功能**，并修正了**批量放置**的问题。

> ⚠️ **本仓库不是原作者的官方仓库**，只是一个民间移植构建。有 bug 请提到本仓库的 Issue。
> 只提供 **Minecraft 26.3** 的版本。

---

## 功能

| 功能 | 说明 |
|---|---|
| **挖掘模式** | 挖掉投影选区内的方块，支持白/黑名单、可选复用 Tweakeroo 的破坏限制 |
| **破基岩** | 自动破除基岩 |
| **替换模式** | 按「替换方块名单」把方块换成指定的（例如水/岩浆 → 沙/沙砾） |
| **单模 / 多模** | 单模一次只跑一个模式；多模可同时跑，并支持「多模阻断」设优先级 |
| **原木去皮** | 放置原木后自动用斧子去皮 |
| **含水方块** | 自动放冰 + 破冰，让方块含水 |
| **容器同步 / 打印机库存** | 把投影选区内容器物品同步到指定容器，或从「打印机库存」远程取物 |
| **远程交互容器** | 服务器允许时远程打开容器取物 |
| **快捷潜影盒** | 直接从背包里的潜影盒取物品 |
| **拼音搜索** | 物品搜索支持拼音（已内嵌 pinyin4j，无需额外装） |
| 其它 | 精准放置、强制潜行、跳过放置、侦测器放置检测、有序存放、覆盖列表方块、渲染层数限制… |

## 安装

1. 把打印机本体 + 下面的**必装前置**一起放进 `mods`。
2. 启动游戏，打开 Litematica 配置界面，页签栏末尾出现「**投影打印机**」即为加载成功。

## 必装前置 mod


| 文件 | 作用 |
|---|---|
| `malilib-fabric-26.3-0.30.1.jar` | masa 系列配置库 |
| `litematica-fabric-26.3-0.29.0.jar` | 打印机是它的扩展，**必须有** |
| `tweakeroo-fabric-26.3-0.30.0.jar` | 挖掘模式复用它的破坏限制列表 |
| `chest-tracker-port-2.8.4+26.3.jar` | 容器记忆 |
| `where-is-it-port-2.7.5.2+26.3.jar` | 物品搜索 |
| `jackfredlib-0.10.6+26.3.jar` | 坐标 API |
| `yet_another_config_lib_v3-3.9.7+26.3-fabric.jar` | YACL，上面两个的硬依赖 |
| `quickshulker-3.1.0-26.3.jar` | 快捷潜影盒 |
| `Searchables-fabric-26.3-1.0.2.jar` | 搜索 API |
| `26.3-投影打印机误踢修复补丁.jar` | 见下方说明（作者：ZeroTing） |

### 关于误踢修复补丁

26.3 新增了对「同一游戏刻内多个位置同步包」的校验，而打印机会附带旋转/位置同步包，
导致**被服务器误判并踢出**。这个补丁让服务端按原版流程正常处理这些包。

- 单人存档：直接放进 `mods` 即可
- 联机（自建服务器）：**服务端也要放同一份**

## 使用方法

### 默认热键

| 功能 | 默认键 |
|---|---|
| 打印机开关 | `CAPS_LOCK` |
| **打开设置菜单** | **`Z` + `Y`（两个键一起按）** |
| 切换模式（仅单模生效） | `J` |
| 关闭全部模式 | `Ctrl` + `G` |

> 按键可在设置菜单的「热键」页签里自行修改。若组合键不好按，建议改成单键。
